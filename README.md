# KeyLab · 键盘检测工具

一个纯前端、可离线运行的键盘检测工具，包含 **键位检测** 与 **鼠标连点（CPS）检测** 两个模块。无需安装依赖、不依赖后端、不上传任何数据，双击 `index.html` 即可在浏览器中使用。

参考站点：

- <https://keyboard.bmcx.com/>
- <https://bytenows.com/tools/keyboard-tester>

## 功能

### 键位检测

- 完整的 ANSI 104 键布局：功能键区、主键区、编辑键区、方向键与数字小键盘。
- 基于物理键位 `KeyboardEvent.code` 识别，与系统键盘布局、输入法状态无关，换键盘或改布局也能准确对应。
- 按键按下时实时高亮；松开后保留「已检测」标记，方便排查失灵或未响应的按键。
- 统计已检测键位数量与覆盖率、当前同时按下键数、同时按下峰值（可粗测键盘无冲 / NKRO 表现）、累计按键次数。
- 按键详情面板展示 `event.key`、`event.code`、`keyCode`、修饰键位置、是否为长按重复触发及触发时间。
- 最近 12 次按键记录，一键重置全部检测状态。
- 自动屏蔽 Tab、空格、方向键等默认行为，避免测试过程中页面滚动或焦点跳转。

### 连点检测（CPS）

- 可选 1 秒 / 5 秒 / 10 秒测试时长；第一次点击自动开始计时。
- 实时显示点击次数、瞬时 CPS（最近 1 秒点击量）与剩余时间进度条。
- 结束后统计平均 CPS、总点击数、最快 / 最长点击间隔、最高瞬时点击速率。
- 生成「每秒点击分布」柱状图，并标注本轮平均线。
- 最近 6 次成绩保存在浏览器本地，自动标记个人最佳；可手动清空。
- 支持鼠标、触控板 / 触摸屏点击，以及聚焦点击区后按空格或回车计数。

### 其他

- 深色 / 浅色主题切换，偏好保存在本地。
- 可选按键音效（默认关闭），使用 Web Audio 实时合成，无外部音频文件。
- 响应式布局：窄屏下键盘区域可横向滚动，统计卡片自动折行。
- 尊重 `prefers-reduced-motion`，减少动画。

## 快速开始

直接双击打开 `index.html` 即可，全部功能在本地运行。

如需通过本地服务器访问（例如在手机或局域网设备上测试）：

```bash
# 任选其一，在项目根目录执行
python -m http.server 8080
# 或（package.json 中的同名脚本，无需安装依赖）
npm start
```

然后访问 <http://localhost:8080>。

## 使用说明

### 键位检测

1. 默认进入「键位检测」，逐个按下键盘上的按键。
2. 按下的键会高亮为青色，松开后保留已检测标记与右上角圆点。
3. 观察顶部「已检测键位」的覆盖率，确认是否有按键无响应。
4. 同时按住多个键，可查看「同时按下」的峰值，用于粗略判断键盘无冲能力。
5. 点击「重置检测」清空所有标记与统计。

> 说明：`Win`、`Alt+Tab`、`Ctrl+W` 等系统级快捷键可能被操作系统拦截，浏览器无法捕获，属于正常现象。测试时可使用普通字母、数字与功能键。

### 连点检测

1. 切换到「连点检测」，选择 1 / 5 / 10 秒时长。
2. 在虚线区域内点击，第一次点击即开始计时。
3. 倒计时结束后展示本轮结果、每秒分布图，并写入历史成绩。
4. 点击「再来一次」重新开始；历史成绩仅保存在当前浏览器的 `localStorage` 中。

## 依赖说明

工程 **没有任何第三方运行时依赖**：浏览器直接加载本地 CSS 与四个原生 JS 文件即可运行。`package.json` 仅用于声明工程元信息、Node 侧预览脚本，并在 `dependencies` / `devDependencies` 中显式留空，便于依赖审计。

- 运行环境：任意现代浏览器（Chrome / Edge / Firefox 等）。
- 可选工具：Node.js（仅执行 `npm start`）或 Python 3（仅用于本地静态服务器）。
- 无需 `npm install`，不存在构建步骤。

## 技术说明

- 纯静态实现：HTML + CSS + 原生 JavaScript，无构建步骤、无第三方运行时依赖。
- 键位识别使用 `event.code`（物理键位），而非 `event.key`（受布局与修饰键影响），因此不同键盘布局下位置一致。
- 连点计时使用 `performance.now()` 与 `requestAnimationFrame`，比 `setInterval` 抖动更小；页面切到后台时会自动暂停刷新，回到前台后按真实时间结算。
- 图表使用 Canvas 2D 绘制，随容器尺寸与主题变化重绘，无需图表库。
- 本地存储键：`keylab.theme`、`keylab.sound`、`keylab.cps.history.v1`。清除浏览器站点数据即可恢复默认。

## 浏览器兼容性

在 Windows 10/11 下的 Chrome、Edge、Firefox 最新版本中验证。需要支持 `KeyboardEvent.code`、`performance.now()`、Canvas 2D、CSS 自定义属性与 `backdrop-filter`（不支持时仅失去毛玻璃效果）。IE 不受支持。

## 已知边界

- 操作系统级快捷键、键盘固件层处理（如 Fn 组合、多媒体键）以及部分游戏键盘的驱动层改键，浏览器无法感知。
- 无冲 / NKRO 峰值只反映浏览器实际收到的按键事件，不能替代硬件级测试。
- CPS 结果受显示器刷新率、浏览器调度与输入设备影响，仅用于横向对比与娱乐参考。

## 开发

修改 `js/layout.js` 中的布局数据即可增删按键或调整字符标注；样式集中在 `assets/styles.css` 顶部的 CSS 变量中，改主题色只需调整变量。项目使用 git 管理，`.gitignore` 已排除系统文件、依赖缓存与本地临时目录。
